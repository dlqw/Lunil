# Lunil 0.17.0-alpha.9

## Class-value navigation

- Navigation now works on declaration tokens: find references, hover, go-to-definition,
  and rename previously returned nothing when the cursor sat on a declaration itself
  (`local Movable = {}`), because the binder does not record declarations as
  references.
- Find references on a class value — a require alias or the defining module's exported
  class local — includes every require site of that module across the workspace plus
  the class declaration site, in addition to same-file uses.
- Hover on a class value shows a class card: the class name, its module, the declared
  inheritance chain (`Character > GameEntity > Entity`), and the members its own
  module exposes followed by the members inherited from each base module.
- Go-to-definition on a require alias declaration passes through to the exported
  class's declaration line, matching the existing behavior on alias uses.
