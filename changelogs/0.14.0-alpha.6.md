# Lunil 0.14.0-alpha.6

Adds prototype-based Lua OOP and colon-self inference on top of metatable flow facts.

- Recognizes `Class.__index = Class`, prototype inheritance, constructors/factories, singleton instances, mixin members, nested method paths, and metatable-backed instance lookup without requiring annotations.
- Added `LuaPrototypeType`, `LuaObjectModelFact`, and method facts with prototype/instance/base/method projections and bounded precision revocation after dynamic mutation or escape.
- Colon-declared methods receive inferred constructor or instance `self` types; method fields participate in calls, inheritance, overrides, and stable prototype refresh as the class table evolves.
- EmmyLua class fields merge with runtime prototype facts, conflicting runtime shapes report `LUA6019`, and dot/colon invocation mismatches report targeted `LUA6017`/`LUA6018` diagnostics.
