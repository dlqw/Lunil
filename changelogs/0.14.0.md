# Lunil 0.14.0

## Lua front end and semantics

- Added a reusable staged front end with immutable syntax, binding, analysis, lowering, and verification snapshots plus per-stage timing and allocation metrics.
- Hardened Lua 5.1–5.5 grammar selection and recovery, including version-specific attributes, operators, escapes, declarations, and named varargs.
- Added compact retained syntax storage and byte-oriented incremental parsing with deterministic full-parse equivalence and safe fallback at invalid edit boundaries.
- Added unified lexical, member, method, and literal-index reference facts with indexed span, symbol, global, and containing-function queries.
- Added flow-sensitive metatable and metamethod analysis, prototype-based OOP and colon-`self` inference, shared closure upvalue cells, and path-sensitive nil-chain narrowing.

## Host and workspace analysis

- Added versioned host-analysis contracts for C++, C#, Unity, Godot, and other injected APIs, including overloads, source/implementation mappings, deterministic JSON, and generated Lua stubs.
- Added callback registration and lifetime facts, host-effect facts, and persistence read/write/delete/clear facts with schemas, migrations, key precision, and missing-value nil behavior.
- Added cross-module export and call graphs for Lua and host modules, re-exports, dynamic exports, classes, callbacks, and persistence schemas.
- Added queryable compact workspace snapshots, sharded indexes, bounded parallel queues, dependency-aware invalidation, weak or strong memory caches, and a versioned disk summary cache.
- Added reproducible one-million-line and five-million-line scale profiles without retaining full compiler models in compact snapshots.

## Language tooling

- Added a self-contained LSP 3.17 language server with incremental synchronization, multi-root indexing, diagnostics, completion, hover, signature help, navigation, references, rename, symbols, semantic tokens, inlay hints, call hierarchy, folding, selection ranges, and code actions.
- Added editor queries for cross-module exports, metatables, OOP, closures, nil paths, callbacks, persistence, and external host definitions and implementations.
- Added a trusted-workspace VS Code extension with bundled platform-specific servers for Windows, Linux, and macOS on x64 and ARM64, bounded crash recovery, status and progress UI, cache/reindex controls, tracing, and a virtual host-contract document.

## Compatibility and performance

- Preserved Lua 5.1–5.5 language modes and `netstandard2.1` library assets while adding the `lunil-language-server` package and platform-specific VS Code packages.
