# Lunil 0.17.0-alpha.11

## Annotation navigation

- Type names inside annotations are now navigation targets: go-to-definition on
  `GameEntity` in `---@class Character : GameEntity`, `Vec` in `---@param v Vec`, or any
  named type in `@field`/`@return`/`@type`/`@generic`/`@overload` type expressions jumps
  to the class declaration line (or the alias/enum annotation when no class declares it).
- Find references on a type name reports every annotation mention across the workspace —
  declarations, base lists, parameter and field types — through a new annotation
  reference index in the workspace snapshot; class names additionally include their
  module's require sites.
- Hover on a type name or a declared class name shows the full class card (inheritance
  chain, signatures, doc comments); alias and enum declarations show their kind card.
