# Lunil 0.18.0-alpha.1

## Analysis and workspace improvements

- Added `lunil.require.searchPaths` for resolving `require("A.B.C")` against prefixed workspace modules (`<root>.A.B.C`), with the raw name tried first.
- Added `lunil.analysis.classFactories` for recognizing class factories such as `local X = class("Name", Base, ...)`; configured factories feed prototype analysis, inheritance edges, hover cards, and class hierarchy.
- Expanded require-name expansion into a reusable workspace API so definition lookup and module resolution share one candidate order.
- Added dotted annotation class names (`---@class host.Engine.Utility.TimeUtil`) for generated host-API stubs; navigation, hover, references, and semantic tokens handle full namespace paths.
- Workspace globals now carry over from other workspace files alongside builtin globals, improving cross-file global references.

## Editor navigation and productivity

- Added `lunil.searchEverywhere` workspace-symbol search, `lunil.classHierarchy`, and `lunil.findUsages` commands with keybindings and editor-context menu entries.
- Redesigned hover cards as compact Markdown tables with module and inheritance rows, and added member summaries for locally built structural tables.
- Added semantic classification for dotted namespace/class paths so generated host-API identifiers render consistently.
- Language-server configuration settings for require search paths and class factories apply without a server restart.
