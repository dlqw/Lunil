# Lunil 0.16.0-alpha.2

## Debugging experience

- Added a `lunil` debugger contribution to the VS Code extension: launch configuration snippets
  for Lua scripts, debug adapter discovery (`onDebugResolve:lunil`), and bundled
  `lunil-debug-adapter` executables for all six platform RIDs with checksum verification.
- On the game loop host, a breakpoint hit suspends the operation turn as a suspended operation
  without breaking the loop contract; engine-level resume continues the coroutine to
  completion. Cross-process attach transport remains a v1 limit.
