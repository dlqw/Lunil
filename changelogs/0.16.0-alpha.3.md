# Lunil 0.16.0-alpha.3

## Type diagnostics configuration

- Publicized diagnostic policy for static analysis: the CLI `check` command accepts a repeatable
  `--suppress <code>` option, and the language server reads
  `lunil.server.suppressedDiagnosticCodes` from workspace settings; both feed the existing
  per-workspace suppression set.
- Annotated call and return checks remain enabled by default: mismatches between `---@param`
  declarations and call arguments, and between `---@return` declarations and function returns,
  are reported as `LUA6003` warnings; unannotated code is unaffected.
