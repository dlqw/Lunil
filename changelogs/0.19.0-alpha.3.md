# Lunil 0.19.0-alpha.3

## Shared binary chunk parsing core

The version-specific binary chunk readers (Lua 5.1-5.5) now share one internal byte-level
parsing core for cursor management, scalar reads, and truncation failures, replacing the
byte-identical reader machinery that was cloned per version and had already drifted. The
readers keep their per-version format logic and failure messages, so parsing behavior is
unchanged.

## Common chunk format exception base

The per-version chunk format exceptions (`Lua51ChunkFormatException` through
`Lua55ChunkFormatException`) now derive from a new public `LuaChunkFormatException` base,
so hosts can catch any Lunil binary chunk failure without handling every version type.
Messages, version-specific properties, and construction are unchanged.

## Single binary codec dispatch

A new public `LuaChunkCodec` is the single dispatch point from a chunk format to the
version converters and writers, replacing the per-command version switches in the CLI and
the runtime's binary chunk loader. The canonical Lua 5.4 reader options now translate
automatically for formats with dedicated option records.

## Lua 5.1 adapter split

The Lua 5.1 adapter file (14 types, 1049 lines) is split into per-responsibility files
(model, reader options, exception, reader, converter, writer) with the surrounding code
style normalized. Public types and behavior are unchanged.
