# Lunil 0.14.0-alpha.2

Hardens the versioned Lua parser and its recovery contract across Lua 5.1 through Lua 5.5.

- Added an authoritative grammar feature matrix covering goto and labels, hexadecimal floats, versioned string escapes, bitwise and floor-division operators, local attributes, Lua 5.5 prefix attributes, global declarations, and named varargs.
- Added cancellation polling and a non-bypassable recursion safety ceiling while preserving lossless token recovery and deterministic diagnostics for malformed input.
- Added dedicated diagnostics for unsupported hexadecimal floats, versioned string escapes, and unknown variable attributes.
