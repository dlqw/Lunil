# Lunil 0.12.0-alpha.24

## Added

- Added bounded, thread-safe `LuaPatchHistory` for recent terminal rollout-ring summaries and
  operational health counters.
- Added heap-independent history entries for stable ring, distributed, target lifecycle, pause,
  side-effect, and generation-guard outcomes.
- Added total ring duration to `LuaPatchRingCommitResult`.

## Reliability

- History is appended only after target cleanup and traffic restoration complete.
- Capacity is hard-bounded, eviction is observable, and concurrent readers receive one consistent
  oldest-to-newest snapshot.
- Recoverable history-recording failures are counted without changing the terminal rollout result
  or adding a partial entry.
- Operational entries omit raw exceptions, failure messages, execution results, module records,
  Lua values, and patch payloads so history cannot retain candidate heap graphs.
