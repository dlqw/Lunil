# Lunil 0.22.0-alpha.8

## One cohesive reference executor

The tier 0.5 compact interpreter loop is no longer a separate static class
reached through a static-import bridge: LuaTier05Interpreter dissolves into
the reference executor as a partial implementation
(LuaInterpreterInstructionExecutor.Tier05.cs), so the executor, its compact
loop, and the canonical instruction core form one type with no cross-class
static seam.

The loop methods remain parameter-threaded pure algorithms by design: the
reference executor can serve engines other than the one that constructed it
(embedding tests wrap it as a delegating executor), so the engine flows as a
parameter instead of being captured as field state, and the stateless
members stay static. The generated-code ABI entry points (LuaCodegenAbiV1-V5)
remain the explicit boundary for reflection-emitted calls and keep their
exact static signatures.

Behavior, tiering, and code generation are unchanged; public APIs are
unchanged.
