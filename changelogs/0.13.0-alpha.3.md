# Lunil 0.13.0-alpha.3

## Added

- Added an AOT-safe CLR binding registry and incremental source generator for constructors, methods, properties, fields, events, delegates, and explicitly registered closed generic types.
- Added generated delegate and event adapters plus Unity `link.xml` preservation metadata for registered bindings.
- Added configurable enum and decimal representations, collection and bounded iterator projection, Tuple and ValueTuple conversion, and named ref/out results.
- Added conversion depth, item, byte, cycle, cancellation, and malformed-collection guards with stable CLR bridge error codes.

## Changed

- CLR binding resolution can now run in registry-only mode or prefer generated bindings before reflection fallback.
- Member, event, delegate, type, and assembly allowlists now reject overlapping name forms instead of selecting an ambiguous entry.
- Portable and NativeAOT consumers can use generated bindings without application-owned reflection preservation annotations.
- The `Lunil.Hosting` package now includes the CLR binding source generator as a C# analyzer asset compatible with C# 9 consumers.
