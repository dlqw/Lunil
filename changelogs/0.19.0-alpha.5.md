# Lunil 0.19.0-alpha.5

## Internal JIT registry restructuring (no behavior change)

The tiered JIT registry (4,500 lines) is now split across partial files by responsibility
(execution, profile state, lifecycle, routing and observation, compilation, cache and
guards, nested types). The host-facing JIT statistics conversion and the JIT policy and
warmup-status mappings are explicit functions instead of unchecked numeric casts, and a
new contract test keeps the host statistics mirror in lockstep with the JIT statistics
record, so adding a counter can no longer drift the four hand-synced copies. No public
API or observable behavior changes; the CodeGen, Hosting, Runtime, and differential
suites validate parity.
