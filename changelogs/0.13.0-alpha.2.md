# Lunil 0.13.0-alpha.2

## Added

- Added the engine-neutral `LuaGameLoopHost` for Update and FixedUpdate scheduling, cross-frame coroutine continuation, manual resume, cancellation, bounded draining, and frame-boundary publication.
- Added injectable monotonic time, main-thread dispatch, console, module, asset, and persistent-store services for portable game-engine adapters.
- Added non-blocking CLR task continuations and linked cancellation through the game-loop queue.

## Changed

- Void CLR delegate callbacks and host-polled timers can run as yieldable Lua coroutines when attached to a game-loop host.
- Frame scheduling now applies explicit callback and canonical-instruction budgets and reports charged instruction counts.
- Scene cancellation invalidates queued work, old callback generations, and outstanding timers before a later frame can resume them.
