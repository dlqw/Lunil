# Lunil 0.17.0-alpha.10

## Class hover cards

- Class-value hovers are now full class cards: a syntax-highlighted
  `class Character : GameEntity` header, the module, the complete declared inheritance
  chain, and the file's leading doc comment as the class description.
- Members list real signatures — `gainExperience(amount: number): boolean` — built from
  the workspace's exported function types, with fields shown as `name: type`; methods
  sort before fields and each group is capped with an overflow marker.
- Each member carries its leading `---` doc comment (annotation directives are skipped),
  so `mitigate(incoming: number): number — Damage after defense mitigation.` reads
  directly in the card.
- Inherited members are grouped per base class (`Inherited · Object`) with the same
  signature and doc treatment; open-class dynamic placeholders no longer appear as
  members.
