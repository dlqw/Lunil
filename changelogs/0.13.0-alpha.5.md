# Lunil 0.13.0-alpha.5

## Added

- Extended the Unity package's IL2CPP support across Windows, Android, and WebGL for Unity 2022.3 LTS and Unity 6; iOS player generation is also supported before the final macOS build step.
- Added IL2CPP-safe generated constructors, properties, methods, delegates, events, closed generics, signed patch application, scene teardown, and Unity resource handling.

## Changed

- Unity IL2CPP hosts now support High managed stripping with registry-only CLR bindings and non-blocking main-thread dispatch on threaded players and WebGL.
- Unity 6 Android hosts use the Activity application entry point while retaining the same IL2CPP runtime integration.
