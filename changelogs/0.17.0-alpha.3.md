# Lunil 0.17.0-alpha.3

## Language server navigation, highlighting, and completion

- Go to definition now covers member references: `module.field`, `object:method`,
  and `t["key"]` resolve through workspace exports to the defining file and line,
  with same-file member writes as the fallback for locally built tables and
  metatable classes. `require("...")` strings open the required module file.
- Find references on a member returns every same-file occurrence plus the cross-module
  definition site when the member is a workspace export.
- Hover over a member shows its inferred member type.
- Semantic tokens now include member references: method calls, plain calls, and
  field accesses receive distinct token types (`method` joins the legend), and the
  modification/readonly/captured modifiers are emitted on the unified reference
  projection. Single-file sessions collect the same projection as workspace
  modules, so highlighting matches in both modes.
- Completion is cursor-aware: after `.` or `:` only the receiver's members are
  offered (module exports for `require` aliases, inferred shape members otherwise,
  function members only after `:`), inside `require("...")` the workspace module
  names are offered, and the generic context ranks file-local symbols before
  workspace exports and keywords.
- Fixed a language server hang: opening a document while every registered
  workspace folder was empty or missing on disk left the declaration gate closed,
  blocking all later analysis requests for that session.
