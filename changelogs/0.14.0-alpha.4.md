# Lunil 0.14.0-alpha.4

Adds a unified, indexed reference model for lexical names, members, methods, and bracket access.

- Preserved `LuaSemanticModel.References` lexical binding behavior while adding ordered `MemberReferences` and `UnifiedReferences` projections without inventing symbols for table members.
- Member and index facts now retain receiver/index spans, read/write/call/method access, containing function IDs, literal candidates, and explicit dynamic or incomplete resolution reasons.
- Added cached span, symbol, global-name, and function-interval indexes with exact-span, position, symbol, and containing-function queries.
- Fixed member-call coverage so `foo.bar()` and `self:helper()` expose `bar` and `helper` to analysis and editor consumers.
