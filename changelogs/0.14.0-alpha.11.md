# Lunil 0.14.0-alpha.11

- Added a VS Code extension for Lua that starts the bundled Lunil language server only in trusted workspaces and provides status, progress, restart, reindex, cache clearing, output, and virtual host-contract commands.
- Added configuration forwarding for external host contracts, server tracing, managed-heap limits, and optional compatible server overrides; the extension reacts to configuration changes and displays injected C++, C#, and engine APIs as a virtual document.
- Added bounded automatic recovery from unexpected language-server termination without collecting telemetry or making runtime network requests.
- Added platform-specific VSIX packaging for Windows, Linux, and macOS on x64 and ARM64. Each package contains one self-contained server, its SHA-256 checksum, and the project license.
