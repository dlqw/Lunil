# Lunil 0.19.0-alpha.6

## DAP request correlation fix

The game-loop debug server's attach relay now correlates DAP requests by their `id`
field, as the protocol requires, instead of the message sequence number. Third-party DAP
clients whose request `id` differs from `seq` (for example VS Code) no longer receive
responses matched to the wrong request.

## Class-factory scanning moved to the analysis layer

The byte-level scanner that detects `extend`, `mixin`, and configured class-factory
definitions moved from the language server workspace into a reusable public
`LuaClassFactoryScanner` in the analysis layer. Scanning behavior is unchanged; the
scanner is now independently testable and available to hosts.

## Debugger tests poll instead of fixed waits

Debugger adapter tests replaced fixed 200-300 ms waits with bounded condition polling,
removing latency-based flakiness while keeping the same assertions.
