# Lunil 0.17.0-alpha.16

## Navigation and hover

- Class inheritance now follows runtime `local X = Y:extend(...)` edges in addition to
  declared `---@class X : Y` bases. Chains that stop at an undeclared base
  (`---@class System` built from `Class:extend`) previously cut inherited members off:
  go-to-definition and hover on `SpawnSystem:new(...)` returned nothing. `new`,
  `extend`, and every other class-library member now resolve to the module that
  declares them, member completion offers them, class hover cards list the runtime
  base group and include it in the Extends row, and the analyzer's known-member table
  follows the same edges (no `has no known member` false positives through them).
- Array-shaped tables (`local systems = { A:new(), B:new(), ... }`) no longer render as
  `{[unknown]: any, [unknown]: any, ...}` in hovers: structural tables with two or more
  unnamed positional entries — or more than four fields — summarize as `table`.
