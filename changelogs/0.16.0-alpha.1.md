# Lunil 0.16.0-alpha.1

## Debug Adapter Protocol kernel

- Added a host debugger session (`LuaDebugSession`) attached to a Lua state with a breakpoint
  set, asynchronous pause requests, and step into/over/out state machine; the execution engine
  suspends the whole scheduling turn at debug checkpoints and reports the new
  `LuaVmSignal.Paused` signal. Coroutines suspended by a debug pause resume through Lua-side
  `coroutine.resume`, and `LuaInterpreter.ResumeDebugged` restores the suspended coroutine chain.
- Added `lunil-debug-adapter`, a Debug Adapter Protocol server (`--stdio`) that launches Lua
  scripts with breakpoints, continue, next, step in, step out, pause, stack traces, scopes, and
  local/upvalue variables, and reports `stopped`/`terminated`/`output` events.
- Kept the reference interpreter as the debug execution backend; debug sessions run at exact
  instruction dispatch while non-debug execution is unchanged.
