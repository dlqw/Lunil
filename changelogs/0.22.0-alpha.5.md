# Lunil 0.22.0-alpha.5

## Instance-owned standard library modules

The standard library libraries that read host configuration become sealed
instance modules that own their options directly:

- basic, io, os, package, and debug register their functions through module
  instances constructed with the resolved options, so 27 per-call state
  service lookups (console, file system, environment, clock, locale, warning
  toggles) become direct field reads on the owning module.
- Reinstalling the standard library on an existing state keeps its documented
  reconfiguration behavior: the facade configures the state service first and
  constructs fresh module instances, and re-registration overwrites the
  previously installed functions.
- print keeps its historical shape: the official Lua test corpus asserts it
  has no captured upvalues, so its body continues to resolve the console
  through the state service on each call.
- Stateless libraries (math, string, table, utf8, bit32, and the string
  pattern/format/pack engines) remain pure static engines by design.

Public APIs are unchanged; all library classes and the module pattern are
internal.
