# Lunil 0.12.1

Lunil 0.12.1 hardens the opt-in CLR bridge without changing its capability or exact-allowlist
model.

## CLR execution and async safety

- Serialize interpreter, JIT, delegate, event, and timer entry through one per-state execution
  boundary. `AnyThreadWhenIdle` callbacks now atomically claim an idle state or fail with
  `ThreadDenied` instead of racing owner-thread execution.
- Reject synchronous waiting on an incomplete CLR task while a `SynchronizationContext` is active,
  avoiding the common single-thread game-loop deadlock. Host schedulers can integrate the public
  `LuaClrTask.Task` directly.
- Preserve the delegate callback adapter and generic task-result metadata for NativeAOT. Delegate
  conversion and `Task<TResult>` results are covered by the NativeAOT publish fixture.

## Conversion and allowlist diagnostics

- Convert rectangular and non-zero-lower-bound CLR arrays into one-based nested Lua tables while
  retaining recursive jagged-array behavior.
- Report `ulong` values above the Lua integer range with `InvocationFailed` instead of silently
  changing them into userdata.
- Fail explicitly with `MemberNotFound` when allowlisted member candidates exceed
  `MaximumCachedMembers`; member caches no longer silently discard candidates.
- Recommend type-qualified member allowlist entries and document that a bare member name applies to
  every allowlisted type.

## Documented conversion boundaries

- Document the synchronous `clr.await` contract, enum string representation, decimal-to-float
  precision boundary, multidimensional array projection, and NativeAOT requirements in the English
  and Simplified Chinese CLR interoperation guides.
