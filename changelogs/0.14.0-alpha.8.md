# Lunil 0.14.0-alpha.8

- Added deterministic workspace export graphs for Lua modules, host-injected modules, functions, classes, re-exports, dynamic exports, callback targets, and persistence schemas.
- Extended workspace call graphs with real cross-module export and function keys, candidate sets, resolution reasons, Lua definition spans, and external definition/implementation locations.
- Added conservative handling for reassigned module aliases, literal-index calls, open exports, cyclic re-exports, and host modules resolved without filesystem fallbacks.
- Added export-symbol, function-summary, and combined analysis hashes for fixed-point convergence and dependency-aware workspace cache invalidation.
