# Lunil 0.17.0-alpha.15

## Hover cards

- Hovering a standard library table receiver (`math` in `math.max`) now shows a compact
  library card — the library name, its member count, the library's doc comment, and a
  link into its readonly page — instead of dumping every member of the table as one
  unreadable line.
- Values typed as large structural tables (more than four fields) summarize as `table`
  in identifier and member hovers; small tables keep their inline shape display.
- Signature type names are linked: member hovers, identifier hovers, and class cards
  append a `**Types**` / `**类型**` row with a clickable link for each workspace class
  the signature mentions (links cannot render inside fenced code blocks, so they sit
  directly under the signature).
- Primitive annotation types (`number`, `string`, `boolean`, `nil`, `any`, `unknown`,
  and friends) now hover with a short bilingual description instead of nothing; the
  same descriptions localize with `lunil.locale`.
- Each standard library page gained a one-line doc comment (`Standard mathematical
  functions and constants.`, ...) that surfaces on the library's hover card.
