# Lunil 0.14.0-alpha.5

Adds flow-sensitive metatable and metamethod semantics to Lua type analysis.

- Added `LuaMetatableType` and `LuaMetatableFact` to distinguish raw table storage, attached metatables, effective lookup, and conservative precision state.
- `setmetatable`, `getmetatable`, `rawget`, and `rawset` now update and query flow types, including reference-identity alias propagation and fail-closed widening after dynamic escape.
- Effective reads and writes support table/function `__index`, `__newindex`, `__call`, `__len`, `__pairs`, arithmetic/comparison/bitwise metamethods, bounded recursive lookup, and union-aware fallback.
- Lua 5.1 table length keeps raw-length behavior while Lua 5.2–5.5 use `__len`; regression coverage includes raw/effective access, aliases, dynamic escape, calls, operators, iteration, and all supported language versions.
