# Lunil 0.17.0-alpha.2

## VS Code extension experience

- Reworked the Lunil status item: distinct icons for starting, ready, indexing,
  restarting, stopped, restricted, and error states; indexing shows a live
  percentage; the error state uses the error background; and clicking the item now
  opens a Lunil menu (index status, reindex, restart, host contract, cache, output,
  settings) instead of only the output channel.
- The status item now returns to the ready state when indexing completes, tracking
  the server's work-done progress and the index progress stream; progress updates
  are throttled so large repositories no longer flood the output channel or churn
  the status bar.
- Added a five-step **Get Started with Lunil Lua** walkthrough covering indexing,
  editing features, host contracts, and debugging, with command links.
- Added a curated Lua snippet library for common idioms (`lf`, `forn`, `class`,
  `pcall`) and Lunil annotation comments (`--class`, `--param`, `--return`,
  `--type`, `--alias`, `--field`, `--generic`, `--overload`).
- Upgraded the Lua language configuration with indentation rules for blocks and
  multi-line constructs, Enter rules that continue `--` comments and auto-indent
  between block headers and `end`/`until`, and a word pattern that selects full
  `a.b.c` member chains on double-click.
- **Lunil: Reindex Workspace** and **Lunil: Clear Analysis Cache** now confirm with
  a transient status message, and **Lunil: Show Index Status** lists documents by
  workspace-relative path with match-on-description search and opens the selected
  file.
- Fixed a file-watcher leak that stacked a new `*.lua` watcher on every server
  restart, sending duplicate change events to the server after each restart.
- Polished settings metadata: ordered settings, enum descriptions for LSP tracing,
  and markdown descriptions with cross-links; added the Debuggers category.
