# Lunil 0.17.0-alpha.12

## Lua standard library support

- The language server embeds an annotated definition of the Lua standard library —
  global functions (`print`, `type`, `pcall`, `setmetatable`, ...), `string`, `table`,
  `math`, `os`, `io`, `coroutine`, `utf8`, and `debug` — analyzed with the same front
  end as user code, so stdlib members carry real annotated signatures in hover and
  completion.
- Hovering a stdlib member or global shows its signature, its documentation, and a
  link into the readonly builtin library; go-to-definition opens the builtin document
  (`lunil-builtin:lua`) at the definition.
- Member completion after `string.`, `table.`, `math.`, and the other library tables
  lists the annotated members with their signatures.

## Hover card links

- Hover cards are now interactive: the module name and every member name link to their
  definitions through `lunil._openLocation`, and builtin members link into the readonly
  library document through `lunil._openBuiltinLocation`; plain workspace locations open
  the target file at the definition position.
