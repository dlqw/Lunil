# Lunil 0.14.0-alpha.9

- Added `AnalyzeCompactAsync` and queryable compact workspace snapshots with sharded reference, call, callback-registration, persistence-schema, and global-name indexes plus on-demand full-model materialization.
- Added per-export, per-function, dependency, and host-contract summary invalidation so private implementation changes do not unnecessarily invalidate importers.
- Added bounded worker queues, SCC-level parallel analysis, progress reporting, iterative graph traversal, streaming discovery/analysis, and configurable backpressure for very large workspaces.
- Added entry-and-byte-bounded weak analysis caches, optional strong retention, reclaimed-model metrics, and a versioned, content-addressed disk summary cache with corruption recovery and byte-budget pruning.
- Added reproducible workspace scale profiles through five million Lua lines; the L and XL profiles retain compact indexes without keeping compiler syntax, semantic, analysis, or IR models resident.
