- Added diagnostics, completion, hover, signature help, definition/declaration/type-definition/implementation navigation, references, collision-checked rename, document/workspace symbols, semantic-token deltas, inlay hints, call hierarchy, folding, selection ranges, and diagnostic code actions.
- Connected Lua, annotation, cross-module export, closure/upvalue, callback, persistence, and host-contract facts to editor queries, including external definition and implementation source mappings.
- Interactive requests remain prioritized while background workspace indexing is active.
