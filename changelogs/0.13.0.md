# Lunil 0.13.0

Lunil 0.13.0 is the stable portable and game-engine hosting release. It adds a shared bounded frame
scheduler, AOT-safe CLR bindings, first-class Unity 2022.3/Unity 6 support, and Godot 4.4 and 4.6 .NET
integration while retaining the optimized .NET 10 host.

## Portable hosting

- Added `netstandard2.1` assets for the compiler, language services, canonical IR, runtime, standard
  library, workspace, and Hosting packages alongside their `net10.0` assets.
- Added deterministic interpreter selection for portable and no-dynamic-code environments. .NET 10
  `Auto` execution continues to use the CIL JIT when available.
- Decoupled the public Hosting JIT options, statistics, and patch-warmup contracts from
  `Lunil.CodeGen.Cil`, so portable consumers use one Hosting API without loading a dynamic-code
  assembly.

## Game-loop hosting

- Added `LuaGameLoopHost` with Update/FixedUpdate phases, cross-frame coroutine continuation,
  explicit resume and cancellation, CLR task continuations, timers, and frame-boundary patch
  publication.
- Added owner-thread dispatch plus injectable monotonic time, console, module, asset, and persistent
  storage services.
- Added bounded callback, instruction, and queue admission with per-tick failures and telemetry-ready
  operation counts.

## AOT-safe CLR interoperation

- Added exact CLR binding registries and a C# source generator for constructors, methods, properties,
  fields, indexers, delegates, events, and allowlisted closed generic types.
- Added `RegistryOnly` execution for NativeAOT, IL2CPP, and trimming, while preserving an explicit
  `RegistryThenReflection` mode for trusted .NET hosts.
- Added configurable enum, decimal, collection, iterator, tuple, and ref/out representations with
  depth, item, byte, cycle, and cancellation limits.

## Unity

- Added the offline `com.dlqw.lunil` UPM package with precompiled portable assemblies, `.lua` asset
  importing, module resolution, persistent storage, engine clocks and console routing, and a
  `LuaUnityGameLoop` component.
- Added first-class Unity 2022.3 LTS and Unity 6 support without requiring 2022.3 projects to upgrade.
  Runtime support covers Editor/Mono and IL2CPP; platform coverage includes Windows, Android, WebGL,
  and iOS generated-player compilation.
- Added Editor lifecycle cleanup and C# 9-compatible binding precompilation for IL2CPP and managed
  stripping.

## Godot

- Added the `Lunil.Godot` NuGet package and offline addon for Godot 4.4 and 4.6 .NET.
- Added process/physics lifecycle hosting, pause and scene teardown, ResourceLoader-backed Lua
  resources, module resolution, persistent storage, console and clock adapters, and typed signal
  subscriptions.
- Added stable desktop and Android support. Godot iOS is preview and requires the official macOS
  toolchain; Godot Web is not part of the 0.13 support contract.

## Compatibility

- Lua 5.4.8 remains the default, with explicit Lua 5.1–5.5 source and binary-chunk contracts.
- CLR interoperation remains opt-in and fail-closed. Engine and AOT deployments should use exact
  generated bindings and `LuaClrBindingMode.RegistryOnly`.
- Host-facing `LuaJit*` option/statistics types move to their `LuaHostJit*` equivalents, CLR decimal
  values default to exact strings, overlapping allowlist forms are rejected, and
  `LuaClrInvocationResult` is no longer a record.
