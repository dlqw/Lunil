# Lunil 0.16.0-alpha.4

## Cross-module type data

- Exposed module export types through the workspace export graph for cross-module consumers
  (already consumed by definition and hover); full cross-module type consistency diagnostics
  are not provided in this prerelease.

## Debugger attach semantics

- Attaching a debug session to a game-loop host keeps the v1 engine-level semantics: a
  breakpoint hit suspends the operation turn, and engine-level resume continues the coroutine.
