# Lunil 0.17.0-alpha.8

## Server stability

- Fixed a crash that took down the whole language server process: a
  `$/cancelRequest` racing the response of an already-completed request cancelled
  a disposed token source. Late cancellations are now ignored instead of escaping
  into the message loop.
- A workspace rebuild that was in flight when a configuration change replaced the
  internal workspace no longer fails with "Cannot access a disposed object"; it
  retries once on the live workspace and its result is still subject to the
  generation guard.
- Informational lifecycle messages (folder loading, declaration scans) are delivered
  through `window/logMessage` instead of stderr, so editors no longer present them
  as errors in the output channel.
