# Lunil 0.12.0-alpha.23

## Added

- Added `LuaPatchGenerationSnapshot` and `LuaHost.CapturePatchGenerationSnapshot()` for one
  host-wide view of active, pending, quiesced, and stale generation-tracked callbacks, tasks,
  timers, and native continuations.
- Added `LuaPatchGenerationGuardPolicy` with per-resource stale budgets and transition-residue
  rejection for production rollout rings.
- Added decision-time generation snapshots to `LuaPatchTargetCommitResult` when a guard is enabled.

## Reliability

- Generation guards run after publication and application health checks but before replay
  acceptance and distributed `Healthy` acknowledgement.
- A guard violation returns `GenerationRejected` and atomically rolls every local ring target back
  to its previous live generation.
- Invalid budgets fail before update-window acquisition, while omitting the guard preserves the
  existing rollout behavior.
