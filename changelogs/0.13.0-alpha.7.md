# Lunil 0.13.0-alpha.7

## Added

- Added consistent long-running gameplay behavior across the portable host, Unity 2022.3 LTS, Unity 6, and Godot 4.4 and 4.6 for deterministic input, update and fixed-step coroutines, logical timers, table-backed collections, persistent snapshots, signed patch publication, health-check rollback, and resource release.
- Added Godot Android .NET export support for Godot 4.4 and 4.6 with the same game-loop and persistence contracts as desktop hosts.

## Changed

- Godot 4.4 mobile consumers target .NET 8, while Godot 4.6 mobile consumers use the export templates' required .NET 9 target.
- Godot iOS remains preview because its official C#/.NET exporter requires macOS.
