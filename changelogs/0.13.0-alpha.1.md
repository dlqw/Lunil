# Lunil 0.13.0-alpha.1

## Added

- Added `netstandard2.1` package assets for the compiler, language services, interpreter runtime, standard library, workspace, and Hosting stack while retaining optimized `net10.0` assets.
- Added portable Hosting JIT configuration, statistics, and warmup contracts so embedders can use the same host API without referencing the dynamic-code package.
- Added deterministic interpreter fallback for portable and no-dynamic-code environments across Lua 5.1 through Lua 5.5; explicitly requesting JIT in those environments now reports `PlatformNotSupportedException`.

## Changed

- `LuaHostOptions.Jit`, `LuaHost.JitStatistics`, and patch warmup configuration now use the `LuaHostJit*` contracts in `Lunil.Hosting`; the `net10.0` host continues to use the CIL JIT backend.
- Durable hot-update file replacement now uses write-through atomic replacement on Windows and same-filesystem atomic rename with directory synchronization on Unix.
