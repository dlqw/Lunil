# Lunil 0.14.0-alpha.3

Adds compact retained syntax storage and byte-oriented incremental parsing.

- Parsed trees now retain a pre-sized compact node/element/token/trivia arena and materialize the existing syntax-node facade on demand; descendant traversal uses explicit stacks for deep trees.
- Added `LuaTextChange` and `LuaParser.ParseIncremental` with top-level suffix reparsing, unchanged-prefix reuse metrics, deterministic diagnostic remapping, and full invalidation when lexer/parser configuration or language version changes.
- Incremental parsing preserves BOM, shebang, long-bracket, and trivia behavior and falls back to a full parse for edits that split UTF-8 code-unit boundaries.
