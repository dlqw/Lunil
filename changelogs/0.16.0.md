# Lunil 0.16.0

## Debugger

- Debug Adapter Protocol support: a host debug session (`LuaDebugSession`) with breakpoints,
  asynchronous pause, and step into/over/out; the execution engine suspends the whole scheduling
  turn at debug checkpoints and reports `LuaVmSignal.Paused`. Coroutines suspended by a debug
  pause resume through the interpreter's debug-pause path.
- `lunil-debug-adapter`, a DAP server over stdio: launches Lua scripts with breakpoints,
  continue, next, step in, step out, pause, stack traces, scopes, and local/upvalue variables.
- VS Code `lunil` debugger type: launch configurations for scripts and attach configurations for
  game-loop hosts; the adapter executable is bundled for all six platform RIDs with checksum
  verification.
- Cross-process attach: `LuaGameLoopHost.StartDebugServer` exposes a named-pipe DAP endpoint
  (`LuaGameLoopDebugServer`); the adapter relays frames verbatim (`--stdio --pipe <name>`), and
  resumes are queued into the game loop's next tick through
  `LuaHost.ResumeDebuggedThread`. JIT hosts are rejected with a clear error.
- Debugging requires the reference interpreter backend; the managed C-stack guard is tuned so
  deep `coroutine.close` chains raise "C stack overflow" with margin instead of exhausting the
  managed stack.

## Type checking

- Annotation-driven bounded flow analysis is enabled by default for annotated files: type
  assignability, argument counts, nil paths, unreachable code, and related `LUA6000`-line
  diagnostics; unannotated files are unaffected.
- Cross-module export consistency (`LUA6022`): a `---@type` on a `require` consumer is compared
  against the resolved module's exported type at the workspace level.
- Suppression through `SuppressedDiagnosticCodes` everywhere: CLI `--suppress <code>`
  (`check`, `build`, `dump`), `lunil.server.suppressedDiagnosticCodes`, or
  `LuaAnalysisOptions` when embedding.

## Compatibility

- `0.16.x` becomes the stable line; the 0.15 API surface remains source compatible, and the
  `api/0.16.0/` baseline is frozen.
- Behavior changes: type diagnostics are enabled by default for annotated files (additive
  diagnostics; unannotated code is unaffected), and `LuaVmSignal.Paused` is a new enum member.
- See the [migration guide](docs/migration-0.16.0.pub.md) for the complete checklist.
