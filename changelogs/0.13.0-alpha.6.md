# Lunil 0.13.0-alpha.6

## Added

- Added a `Lunil.Godot` NuGet integration and offline-installable Godot addon for Godot 4.4 and 4.6 .NET projects.
- Added Godot node lifecycle hosting for process and physics ticks, tree pause handling, scene reload, tree exit, predelete, and queued-free disposal.
- Added ResourceLoader-backed Lua resources and module resolution, Godot console, time, dispatcher, persistent-store adapters, and typed signal subscriptions with automatic disconnect.
- Added desktop export support for Godot 4.4 and 4.6 .NET on Windows, Linux, and macOS targets.

## Changed

- Godot hosts support signed frame-boundary patch publication, process/physics phase isolation, pause and resume behavior, signal teardown, resource round-tripping, and host replacement.
