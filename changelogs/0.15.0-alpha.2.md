# Lunil 0.15.0-alpha.2

- Add a bounded non-variadic C ABI signature parser with scalar, pointer, and UTF-8 string types.
- Add dynamic delegate adaptation where runtime dynamic code is available and exact registry bindings for AOT or trimmed hosts.
- Marshal fixed-width integers, pointer-sized values, floating-point values, booleans, UTF-8 arguments/results, null pointers, and stable conversion failures.
- Add native invocation error conversion and Windows C ABI smoke coverage for an allowlisted system symbol.
