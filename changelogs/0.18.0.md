# Lunil 0.18.0

## Workspace and analysis

- Added `lunil.require.searchPaths` for resolving `require("A.B.C")` against prefixed workspace modules (`<root>.A.B.C`), with the raw name tried first; useful for monorepos and client/server Lua roots.
- Added `lunil.analysis.classFactories` for recognizing class factories such as `local X = class("Name", Base, ...)`. Configured factories feed prototype analysis, inheritance edges, hover cards, and class hierarchy.
- Require-name expansion is now a reusable workspace API, so definition lookup and module resolution share one candidate order.
- Workspace globals from other workspace files now carry over alongside builtin globals, improving cross-file global references.
- Dotted annotation class names (`---@class host.Engine.Utility.TimeUtil`) are accepted for generated host-API stubs; navigation, hover, references, and semantic tokens handle full namespace paths.
- Compact snapshots can save and restore navigation data, and restored contributions can be adopted into an existing workspace.

## Editor productivity

- Added `lunil.searchEverywhere` workspace-symbol search, `lunil.classHierarchy`, and `lunil.findUsages` commands with keybindings and editor-context menu entries.
- Redesigned hover cards as compact Markdown tables with module and inheritance rows, plus member summaries for locally built structural tables.
- Added semantic classification for dotted namespace/class paths so generated host-API identifiers render consistently.
- Language-server configuration for require search paths and class factories applies without restarting the server.
