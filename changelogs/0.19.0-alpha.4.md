# Lunil 0.19.0-alpha.4

## Internal runtime engine restructuring (no behavior change)

The execution engine is now split across partial files by responsibility (scheduler,
calls, coroutines, debug hooks, operations, codegen glue, support) instead of a single
5,600-line file, and runtime error forensics moved to a dedicated internal class. Runtime
error classification now uses an internal error-kind channel between producers and the
error enricher, replacing message-prefix sniffing for all central error producers with a
sniffing fallback left only for unclassified host-supplied exceptions. No public API or
observable behavior changes; the full differential and conformance suites validate parity.
