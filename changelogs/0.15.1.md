# Lunil 0.15.1

## Fixes

- Workspace analysis now deterministically reuses the last analyzed snapshot: with the default
  weak result cache, a garbage collection between two consecutive analyses could force a full
  re-analysis. Consecutive analyses of the same documents now always hit the cache, and the
  weak-cache reclamation path remains covered for older entries.
- The language server no longer invalidates the workspace index when a folder load finds no Lua
  files. Previously the empty load raced with an in-flight reindex and could discard a valid
  snapshot, making workspace symbols and references temporarily unavailable.

## Native FFI platform coverage

- Native FFI dynamic loading is now verified on `linux-musl-x64` (Alpine/musl), including the
  `libdl.so.2` to `libdl.so` loader fallback used when the versioned library name is not present.

## Compatibility

- `0.15.x` remains the stable line; no public API changes, no behavioral compatibility changes.
- The `0.15.0` public API baseline remains frozen.
