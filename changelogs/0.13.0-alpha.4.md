# Lunil 0.13.0-alpha.4

## Added

- Added an offline-installable Unity Package Manager integration with precompiled `netstandard2.1` Lunil assemblies for Unity 2022.3 LTS and Unity 6.
- Added `.lua` asset importing, Unity console and time adapters, asset-backed module resolution, persistent storage, and a player-loop host component.
- Added Unity Editor lifecycle integration for assembly reload, play-mode transitions, disabled domain reload, scene disposal, and generated CLR binding precompilation.
- Added C# 9-compatible Unity binding output and isolated Unity 6-only assemblies without raising the package minimum above Unity 2022.3.

## Changed

- Unity-hosted `require` now resolves imported Lua modules through the same asset resolver used by workspace services.
- Unity binding precompilation now discovers all generated registry source names and emits package preservation metadata for AOT consumers.
