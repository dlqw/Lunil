# Lunil 0.14.0-alpha.1

Introduces a reusable staged Lua front end with explicit syntax, binding, analysis, lowering, and verification snapshots.

- Added per-operation elapsed-time and managed-allocation metrics for lexing, annotations, parsing, binding, analysis, lowering, and verification.
- Workspace dependency discovery now advances the same bound snapshot through typed cross-module analysis instead of repeating lexing, parsing, and binding.
- Added a reproducible front-end benchmark fixture for 30 KiB, 300 KiB, 1 MiB, and 2 MiB sources with stage-level allocation and timing output plus peak working-set measurement.
