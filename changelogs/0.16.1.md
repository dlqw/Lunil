# Lunil 0.16.1

- Fixed language-server document symbols, semantic tokens, and inlay hints so interactive document analysis no longer depends on code generation or IR verification.
- Added full exception stack traces to the local language-server diagnostic stream for unexpected request and notification failures while preserving concise JSON-RPC error responses.
- Made the VS Code extension wait with bounded backoff when bundled server checksum files are temporarily unavailable during installation, while keeping manifest and hash failures as hard errors.
