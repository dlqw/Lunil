# Lunil 0.15.0-alpha.3

- Install the opt-in `ffi` module and expose `load`, `bind`, `alloc`, `free`, `read`, `write`, and `close` with Lua-facing error conversion.
- Add bounded native buffers with scalar and C-string read/write operations, pointer-sized storage, bounds checks, allocation budgets, and idempotent free.
- Add rooted userdata metatables with `__gc`/`__close` lifecycle hooks, library lease retention, explicit library close invalidation, and GC-safe alias behavior.
- Add end-to-end Lua coverage for module policy, registry calls, dynamic calls, resource limits, buffer operations, repeated release, and library alias collection.
