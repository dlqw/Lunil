# Lunil 0.17.0-alpha.13

## Fixes

- Hover command links (definitions, the builtin library) render as clickable now that
  the extension marks hover markdown as trusted with the navigation commands allowlisted.
- Go-to-definition on a stdlib library table name (`math`, `string`, `table`, ...)
  opens the readonly builtin document at the library declaration.
- The readonly builtin document shows its content when opened via VS Code's own
  definition opener (F12), not just via hover card links: the content provider now
  fetches the source from the server on demand.
