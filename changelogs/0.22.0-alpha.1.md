# Lunil 0.22.0-alpha.1

## State-scoped runtime services

This prerelease starts the 0.22.0 architecture line. The runtime core no longer
keeps mutable state in process-wide static fields; components that previously
reached through static caches now live on the owning instance graph:

- LuaState gains an internal per-state service registry. The standard library
  stores its per-state context (console, file system, and warning settings)
  there instead of a static attachable table, keeping the documented
  reconfiguration behavior when the library is reinstalled on an existing state.
- Heap identities used by the cross-state safety checks are allocated by an
  explicit identity source instead of a hidden process counter; the public
  LuaHeap constructor is unchanged.
- Module IR verification memoization moved from a process-wide cache onto the
  execution engine instance, so each engine verifies a given module once.
  Verification itself is unchanged and deterministic.
- FFI metatable registry keys are numbered per state instead of per process;
  key uniqueness within a state registry is unchanged.

Behavior, public APIs, and binary compatibility are unchanged.
