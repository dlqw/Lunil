# Lunil 0.16.0-alpha.5

## Cross-module type consistency diagnostics (LUA6022)

- Workspace-level cross-module consistency check: a `---@type` annotation on a `require`
  consumer is compared against the resolved target module's exported type, and an explicit
  mismatch is reported as LUA6022 (warning, analysis phase) in workspace diagnostics.
- Only reports definite incompatibility: unresolved annotations and `any`/`unknown` declared or
  exported types are skipped, so untyped code produces no noise.
- Suppression is shared with the existing `LuaAnalysisOptions.SuppressedDiagnosticCodes` pipeline
  (`--suppress` on the CLI, `lunil.server.suppressedDiagnosticCodes` in the language server).
- `LuaWorkspaceDiagnosticPhase` gains `Analysis` for the new surface.
