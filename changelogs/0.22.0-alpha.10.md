# Lunil 0.22.0-alpha.10

## Packaging for the 0.22.0 line

This prerelease completes the 0.22.0 packaging surface:

- The Lunil.StandardLibrary package ships the native FFI binding generator as
  an analyzer asset, so projects referencing the package can declare
  `[LuaFfiGenerateBinding]` requests without extra references. The generator
  reports `LUNILFFI001`/`LUNILFFI002` diagnostics at build time.
- The bundled C# 9-compatible binding consumers follow the registry-only
  interop API of this line.
