# Lunil 0.22.0-alpha.10

## Release gates for the 0.22.0 line

This prerelease freezes the 0.22.0 development line with its packaging and
compatibility gates:

- The Lunil.StandardLibrary package now ships the native FFI binding
  generator as an analyzer asset; the package compatibility baseline for the
  0.22.0 line records the packaged layout, and the packaged C# 9 binding
  consumer smoke runs against the generated bindings of both generators.
- The package compatibility harness's embedded C# 9 consumer follows the
  registry-only interop API (the LuaClrBindingMode assignment is gone).
- Release evidence recorded with this line: per-RID CLI publish smoke in
  NativeAOT, single-file-trimmed, and ReadyToRun modes; the NativeAOT and
  portable fixtures; and the public API baselines for 0.22.0.
