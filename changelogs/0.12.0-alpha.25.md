# Lunil 0.12.0-alpha.25

## Added

- Added bounded, non-executing `LuaJitExecutor.Warmup` with hot-profile ordering, Tier 1 and
  profile-qualified Tier 2 compilation, cooperative deadlines, and structured per-function results.
- Added optional patch preparation warmup that conservatively remaps live JIT profiles to candidate
  modules before publication.
- Added patch-wide and per-module function and wall-clock budgets, plus best-effort and
  require-success deployment policies.

## Reliability

- Candidate warmup does not execute Lua code, mutate live state, or extend the commit update-window
  pause.
- Caller cancellation propagates while warmup deadlines cancel compiler work owned by warmup and
  restore a cold, retryable function state; shared runtime compilation is not canceled.
- Interpreter and dynamic-code-disabled hosts report `NotApplicable`; bounded candidate code remains
  subject to the existing JIT code-cache limit and eviction policy.
