# Lunil 0.15.0-alpha.1

- Add the disabled-by-default native C ABI FFI contract for explicitly configured standard-library hosts.
- Add exact library and symbol allowlists, stable FFI error categories, configurable resource limits, and a replaceable native loader.
- Add exact host-registered bindings for AOT and trimmed environments, with deterministic signature and registration validation.
- Add opt-in `ffi` module installation and lifecycle-safe library handles with explicit close semantics.
