# Lunil 0.17.0-alpha.23

## Real-time indexing progress in the status bar

- The Lunil status item now shows live per-phase counts while indexing — for example
  `Lunil: reading files 1234/26000`, then `scanning declarations n/total`,
  `discovering modules n/total`, `analyzing n/total` — instead of a bare percentage.
  The tooltip keeps the percentage plus succeeded/in-progress/failed/pending and
  excluded counts.
- File loading and the declaration scan — previously silent phases that can dominate
  startup on huge workspaces — now report real completed/total file counts as they
  run; the standard window progress notification continues to mirror the same counts.
- Progress events from parallel corpus workers are serialized and rate-limited, and
  indexing is only marked complete by the terminal phase (intermediate phases each
  reaching their own n/total no longer flip the status to ready).
