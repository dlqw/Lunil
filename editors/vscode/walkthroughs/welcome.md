# Welcome to Lunil Lua

Lunil brings versioned Lua 5.1–5.5 language intelligence to VS Code: completions,
hover types, signature help, go-to-definition, find references, rename, semantic
highlighting, inlay hints, call hierarchy, and annotation-driven type diagnostics.

The Lunil status item in the status bar shows the server state. Click it to open the
Lunil menu with restart, reindex, cache, and status commands.

<a href="command:lunil.showMenu">Open the Lunil menu</a>
